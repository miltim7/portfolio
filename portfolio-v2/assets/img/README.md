# Места под картинки

Сейчас все визуалы нарисованы кодом (SVG/CSS). Когда появятся картинки от нейросети или скриншоты,
положите их сюда с этими именами и замените `<svg>` внутри соответствующего блока на `<img>`.

| Файл | Где на странице | Пропорции | Размер |
|---|---|---|---|
| `demo-01-chair.webp` | Раздел «Демо», большая картинка (`.slot` 1) | 4:3 | 1600×1200 |
| `demo-02-tools.webp` | Раздел «Демо», слот 2 | 4:3 | 1600×1200 |
| `demo-03-phone.webp` | Раздел «Демо», слот 3 | 4:3 | 1600×1200 |
| `project-01-cover.webp` | Секция «камера влетает» (`.fly-card`), первый настоящий проект | 16:10 (десктоп), 3:4 (телефон) | 2560×1600 и 1200×1600 |
| `share.png` | Превью ссылки в мессенджерах (`og:image`) | 1200×630 | 1200×630 |

Пример замены слота:

```html
<figure class="slot" data-slot="assets/img/demo-01-chair.webp">
  <img src="assets/img/demo-01-chair.webp" alt="Кресло барбера у зеркала" width="1600" height="1200" loading="lazy">
</figure>
```
